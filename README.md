# Minha Vida Financeira — PWA (pacote público seguro)

Este pacote contém apenas o código genérico do aplicativo. Não inclui salários, despesas, dívidas ou outros valores pessoais.

## Publicação
1. Envie os arquivos desta pasta para um repositório público vazio no GitHub.
2. Ative GitHub Pages em Settings > Pages > Deploy from a branch > main > /(root).
3. Abra o endereço HTTPS gerado no Chrome do Android e escolha Instalar app / Adicionar à tela inicial.

## Dados privados
O aplicativo guarda os lançamentos no armazenamento local do navegador/aplicativo. Importe separadamente o arquivo privado de configuração que foi fornecido à usuária. Não envie esse arquivo privado ao GitHub nem a qualquer hospedagem pública.

## Limitações
- Esta versão não tem login, senha, biometria nem sincronização em nuvem.
- Faça backup regularmente usando a função do aplicativo.
- Os dados ficam no navegador/perfil deste aparelho; limpar os dados pode apagá-los.
